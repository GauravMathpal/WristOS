# WristOS — Project Presentation

## Local Development & Build
```bash
cd presentation
npm install
npm run dev
npm run build
```

## Keyboard Shortcuts
- `→` / `Space` — Next slide
- `←` — Previous slide
- `G` — Slide Grid overview
- `P` — Toggle Autoplay
- `F` — Fullscreen
